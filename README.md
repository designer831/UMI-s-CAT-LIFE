## 📑 網站分頁導覽架構

1. **[首頁 Home](index.html)**：迎賓大廳、烏米基本檔案、多頁探索導覽區、即時動態與互動留言板。
2. **[關於烏米 About](about.html)**：皇室機密檔案、2022 年至今的身世起源物語、性格能力數據條與一日行程作息表。
3. **[寫真相簿 Gallery](gallery.html)**：典藏寫真展覽，支援分類切換（睡姿、黑豹姿態、拍屁屁日常）、點圖全螢幕燈箱放大與愛心按讚互動。
4. **[日常日記 Diary](diary.html)**：烏米的生活隨筆日記時間軸（拍屁屁成癮紀錄、隱形藝術、紙箱大作戰）。
5. **[下載專區 Downloads](downloads.html)**：專屬皇室福利，提供 4K 手機直式桌布、4K 電腦寬螢幕桌布、社群表情包頭像與《黑貓拍屁屁飼養秘笈》。
